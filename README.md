# IGV Browser

A minimal [igv.js](https://igv.org/doc/igvjs/) page using the original IGV interface, human hg38, and its default gene track.

[Open the browser](https://eit-gbi.github.io/igv-browser/).

Edit `docs/index.html` to change the genome, starting locus, or add tracks to the IGV configuration. GitHub Pages publishes `/docs` from `main` after each push.

igv.js is pinned to 3.8.10 and loaded from jsDelivr. Site code and igv.js are MIT licensed.
